Simple Calculator

A small four-function calculator, built to show how a display input and a grid of buttons can be wired together with a handful of plain JavaScript functions.

How it's built

After setting up your HTML, CSS and JS files, the front end is just a text input acting as a display, plus a grid of buttons. Below is the button markup you'd drop into your own page to reproduce the layout above.
